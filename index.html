Урок 1: Переменные и вывод

В Python переменные создаются присваиванием. print() выводит текст на экран.

name = "Алиса"
age = 25
print(f"Привет, {name}! Тебе {age} лет.")

Задание 1

Напиши код, который:

  1. Создаёт переменную city со значением твоего города.
  2. Выводит фразу: Я живу в [город].


Подсказка

Используй f-строку: f"Я живу в {city}.".

Урок 2: Условия (if/else)

Условные конструкции позволяют выполнять разный код в зависимости от условия.

score = 85
if score >= 60:
    print("Сдано!")
else:
    print("Не сдано.")

Задание 2

Напиши код:

  1. Переменная temperature равна 22.
  2. Если temperature > 20, выведи: Тепло!
  3. Иначе: Прохладно.


Урок 3: Циклы (for)

Цикл for перебирает элементы в коллекции или диапазоне.

for i in range(3):
    print(i)

Задание 3

Выведи числа от 1 до 5 (каждое с новой строки) с помощью цикла for.



Урок 4: Функции

Функции позволяют переиспользовать код. Они принимают аргументы и могут возвращать значение.

def greet(name):
    return f"Привет, {name}!"

print(greet("Боб"))

Задание 4

Определи функцию square(x), которая возвращает квадрат числа x. Вызови её для числа 5 и выведи результат.
